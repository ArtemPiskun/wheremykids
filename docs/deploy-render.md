# Як викласти сервер в інтернет (Render)

Після цих кроків у вас буде адреса на кшталт `https://moi-dity-server.onrender.com`,
до якої застосунок достукається з будь-якого телефона. Сервер і база стоять у Франкфурті.

**Вартість:** приблизно **$13 на місяць** (сервер $7 + база PostgreSQL $6), оплата карткою.
Безкоштовний план не підходить: сервер засинає без запитів і перестає стежити за тривогами,
а безкоштовна база на Render тимчасова.

Конфігурація вже лежить у репозиторії у файлі `render.yaml`, тож нічого налаштовувати руками не треба.

## Що підготувати

1. **Ключ Firebase** (для пушів). Firebase Console → проєкт `my-kids-1f72d` → ⚙️ Project settings →
   **Service accounts** → **Generate new private key**. Завантажиться JSON-файл. Нікому його не пересилайте.
2. **Перетворити ключ на один рядок (base64)**, бо Render приймає секрети текстом:
   - **Mac** (Термінал, у папці з файлом):
     `base64 -i назва-файлу.json | pbcopy` — рядок уже скопійовано в буфер.
   - **Windows** (PowerShell, у папці з файлом):
     `[Convert]::ToBase64String([IO.File]::ReadAllBytes("назва-файлу.json")) | Set-Clipboard`
3. **Токен alerts.in.ua** — якщо вже видали. Якщо ні, сервер запуститься й без нього,
   просто не надсилатиме тривог; токен можна додати пізніше (крок 8).

## Кроки

1. Зайдіть на https://dashboard.render.com і зареєструйтеся **через GitHub** (кнопка «GitHub»).
2. Render попросить доступ до репозиторіїв: дозвольте доступ до `wheremykids`
   (можна вибрати «Only select repositories»).
3. Додайте картку: аватар угорі праворуч → **Billing** → додати спосіб оплати.
4. Угорі натисніть **New** → **Blueprint**.
5. Виберіть репозиторій `wheremykids`, гілка `main`. Render прочитає `render.yaml` і покаже,
   що створить: сервіс `moi-dity-server` і базу `moi-dity-db`.
6. Render попросить заповнити два секрети:
   - `FIREBASE_SERVICE_ACCOUNT_BASE64` — вставте рядок з буфера (крок 2 підготовки);
   - `ALERTS_IN_UA_TOKEN` — токен або залиште порожнім.
7. Натисніть **Deploy Blueprint** і зачекайте 3–5 хвилин, поки статус сервісу стане **Live**.
8. Відкрийте сервіс `moi-dity-server`. Угорі сторінки буде його адреса
   (`https://moi-dity-server.onrender.com` або з додатковими символами, якщо ім'я зайняте).
   Відкрийте в браузері `<адреса>/healthz` — має з'явитися `{"ok":true}`.
   Секрети потім змінюються тут же: вкладка **Environment**.
9. У вкладці **Logs** мають бути рядки «Пуші через Firebase, проєкт my-kids-1f72d».
   Якщо бачите «Ключ Firebase не задано» — секрет вставлено з помилкою, перевірте крок 6.

## Підключити застосунок

1. GitHub → репозиторій `wheremykids` → **Settings** → **Secrets and variables** → **Actions** →
   вкладка **Variables** → **New repository variable**.
2. Name: `API_URL`, Value: адреса з кроку 8 **без** `/healthz` і без скісної риски в кінці,
   наприклад `https://moi-dity-server.onrender.com`.
3. Перезапустіть збірку APK (вкладка **Actions**) і встановіть новий APK на телефон.

## Що далі відбувається саме

- Кожен merge у `main` автоматично перевикладає сервер (Render сам збирає Docker-образ).
- Міграції бази запускаються самі при старті сервера.
- Історія точок дітей старша за 30 днів видаляється автоматично.

## Якщо щось не так

- **Статус Failed під час збірки** — відкрийте **Logs** і надішліть текст помилки в чат.
- **Застосунок не підключається** — перевірте, що `API_URL` починається з `https://` і що APK
  зібрано вже після того, як ви задали змінну.
- Область дитини поки визначається через OpenStreetMap (`USE_NOMINATIM=1`). Для більшої кількості
  користувачів краще покласти файл меж областей (див. README, `OBLAST_GEOJSON_PATH`).
